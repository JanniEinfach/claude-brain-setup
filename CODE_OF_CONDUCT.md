# Code of Conduct

## Our Standards

- Be respectful and constructive in all interactions.
- Do not include private data, secrets, or credentials in contributions.
- Provide honest, actionable feedback.
- No harassment, discrimination, or personal attacks.

## Scope

Applies to all project spaces: issues, pull requests, discussions, and comments.

## Enforcement

Violations may result in removal from the project. Report concerns via a GitHub issue.
