# Engineering Principles

Inspired by disciplined software craftsmanship. These apply regardless of tools or language.

## Think Before Coding

- State your assumptions before writing code.
- Ask when the requirement is ambiguous rather than guessing.
- Surface tradeoffs — do not hide them.

## Simplicity First

- Write the minimal code that solves the problem.
- No speculative abstractions. No features the user did not ask for.
- If you cannot explain why a line exists, remove it.

## Surgical Changes

- Touch only what the task requires.
- Do not refactor unrelated code during a feature or bug fix.
- Match the existing style and conventions of the codebase.

## Goal-Driven Execution

- Define what "done" looks like before you start.
- Verify against that definition before reporting complete.
- Use tests, type checks, or manual checks — do not just declare it done.
